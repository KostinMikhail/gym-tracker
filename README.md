# Gym — дневник тренировок

Личное Android-приложение для записи тренировок: шаблоны «Фулбади А / Б», выбор упражнения в каждом слоте, подходы × повторы × вес, самочувствие, история и график веса по каждому упражнению. Работает полностью офлайн, данные хранятся на телефоне.

Каждый push в ветку `main` автоматически собирает подписанный APK и публикует его в [Releases](https://github.com/KostinMikhail/gym-tracker/releases). Телефон получает обновления через приложение **Obtainium**.

## Установка на телефон (один раз)

### 1. Установите Obtainium
1. Откройте на телефоне страницу https://github.com/ImranR98/Obtainium/releases/latest
2. Скачайте файл `app-arm64-v8a-release.apk` (подходит почти для всех современных телефонов).
3. Откройте скачанный файл. Если Android спросит — разрешите установку из этого источника (браузера / файлового менеджера).
4. Установите и откройте Obtainium. Разрешите уведомления — так он будет сообщать о новых версиях.

### 2. Добавьте Gym в Obtainium
1. В Obtainium нажмите **«Add App»** (плюс внизу).
2. В поле **«App Source URL»** вставьте:
   ```
   https://github.com/KostinMikhail/gym-tracker
   ```
3. Остальные настройки не трогайте. Нажмите **«Add»**.
4. Obtainium найдёт последний релиз и предложит **«Install»**. Нажмите, затем подтвердите установку в системном окне (при первом разе разрешите Obtainium устанавливать приложения).
5. На рабочем столе появится приложение **Gym**.

### 3. Как приходят обновления
- Когда в `main` появляется новый код, GitHub Actions за несколько минут собирает новую версию (`v1.0.<номер>`).
- Obtainium периодически проверяет обновления (по умолчанию примерно раз в 6 часов; интервал можно поменять в Settings → «Background update checking»). При появлении новой версии придёт уведомление.
- Проверить вручную: откройте Obtainium → потяните список вниз → у Gym появится кнопка **«Update»**.
- Обновление ставится **поверх** текущей версии: все тренировки и история сохраняются. Удалять приложение не нужно и **не следует** — удаление стирает все данные.

## Синхронизация с Google Таблицей

Приложение может копировать журнал тренировок в вашу Google Таблицу: каждое записанное упражнение — отдельная строка на листе **«Журнал»** (дата, тренировка, группа, упражнение, подходы, повторы, вес, ощущение). Правка записи обновляет ту же строку, удаление — удаляет её. Главная копия данных остаётся в телефоне, таблица — её зеркало. Без интернета записи копятся и уходят сами, когда сеть появится. Настраивается один раз, примерно за 10 минут.

### 1. Таблица и скрипт
1. Откройте (или создайте) Google Таблицу, в которую нужно выгружать журнал.
2. В меню таблицы выберите **Расширения → Apps Script**. Откроется редактор скриптов.
3. Откройте файл [`tools/apps-script/Code.gs`](tools/apps-script/Code.gs) в этом репозитории, скопируйте **весь** текст.
4. В редакторе Apps Script удалите всё, что есть в файле `Code.gs`, и вставьте скопированное. Нажмите **💾 Сохранить** (или Ctrl+S).

### 2. Токен (пароль для приложения)
1. Придумайте длинную случайную строку — например, 30–40 букв и цифр вперемешку. Это пароль, по которому скрипт узнаёт ваше приложение.
2. В редакторе слева нажмите **⚙ Настройки проекта** → внизу **Свойства скрипта** → **Добавить свойство скрипта**.
3. Имя: `TOKEN` (большими буквами), значение: ваша строка. Нажмите **Сохранить свойства скрипта**.

### 3. Публикация скрипта
1. Вверху справа нажмите **Развернуть → Новое развёртывание**.
2. Нажмите шестерёнку рядом с «Выберите тип» → **Веб-приложение**.
3. «Запуск от имени»: **Я**. «Кто имеет доступ»: **Все**. Нажмите **Развернуть**.
4. Google попросит разрешить доступ: **Предоставить доступ** → выберите свой аккаунт → если появится «Приложение не проверено», нажмите **Дополнительные настройки → Перейти на страницу проекта** → **Разрешить**. (Это ваш собственный скрипт, он работает только с этой таблицей.)
5. Скопируйте **URL веб-приложения** — он заканчивается на `/exec`.

### 4. Приложение
1. На главном экране нажмите **⚙** справа вверху → «Синхронизация с Google Таблицей».
2. Вставьте ссылку в поле **«Ссылка на скрипт»**, а токен — в поле **«Токен»**.
3. Нажмите **«Проверить связь»** — должно появиться «Подключено ✓». Если нет — текст подскажет причину (неверный токен, не та ссылка, нет интернета).
4. Нажмите **«Выгрузить всю историю»** — все прошлые записи уйдут в таблицу (можно нажимать повторно — дублей не будет). Дальше новые записи выгружаются сами в течение минуты.

### Если поменяли скрипт
После правок в `Code.gs` нажмите **Развернуть → Управление развёртываниями → ✏ (изменить) → Версия: Новая версия → Развернуть**. Так ссылка останется прежней и в приложении ничего менять не нужно. («Новое развёртывание» создаст новую ссылку.)

Чтобы ассистент мог читать прогресс, дайте ему ссылку на саму таблицу с доступом на просмотр (Настройки доступа → «Все, у кого есть ссылка» → Читатель).

## Для разработки

- Kotlin, Jetpack Compose, Material 3, Room, Navigation Compose. minSdk 26.
- Сборка: `gradlew.bat assembleDebug`, тесты: `gradlew.bat testDebugUnitTest`, lint: `gradlew.bat lint`.
- Проверка скрипта таблицы без Google: `node tools/apps-script/Code.test.js`.
- Release-подпись локально — через git-игнорируемый `keystore.properties` в корне:
  ```
  storeFile=C:/Users/<you>/gym-keystore/gym-release.jks
  storePassword=...
  keyAlias=gym
  keyPassword=...
  ```
- В CI подпись берётся из секретов репозитория `GYM_KEYSTORE_BASE64`, `GYM_KEYSTORE_PASSWORD`, `GYM_KEY_ALIAS`, `GYM_KEY_PASSWORD`.
- Правила для изменений и обзор архитектуры — в [CLAUDE.md](CLAUDE.md).
