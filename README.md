# Gym — дневник тренировок

Личное Android-приложение для записи тренировок: шаблоны «Фулбади А / Б», выбор упражнения в каждом слоте, подходы × повторы × вес, самочувствие, история и график веса по каждому упражнению. Работает полностью офлайн, данные хранятся на телефоне.

Каждый push в ветку `main` автоматически собирает подписанный APK и публикует его в [Releases](https://github.com/KostinMikhail/gym-tracker/releases). Телефон получает обновления через приложение **Obtainium**.

## Установка на телефон (один раз)

### 1. Установите Obtainium
1. Откройте на телефоне страницу https://github.com/ImranR98/Obtainium/releases/latest
2. Скачайте файл `app-arm64-v8a-release.apk` (подходит почти для всех современных телефонов).
3. Откройте скачанный файл. Если Android спросит — разрешите установку из этого источника (браузера / файлового менеджера).
4. Установите и откройте Obtainium. Разрешите уведомления — так он будет сообщать о новых версиях.

### 2. Добавьте Gym в Obtainium
1. В Obtainium нажмите **«Add App»** (плюс внизу).
2. В поле **«App Source URL»** вставьте:
   ```
   https://github.com/KostinMikhail/gym-tracker
   ```
3. Остальные настройки не трогайте. Нажмите **«Add»**.
4. Obtainium найдёт последний релиз и предложит **«Install»**. Нажмите, затем подтвердите установку в системном окне (при первом разе разрешите Obtainium устанавливать приложения).
5. На рабочем столе появится приложение **Gym**.

### 3. Как приходят обновления
- Когда в `main` появляется новый код, GitHub Actions за несколько минут собирает новую версию (`v1.0.<номер>`).
- Obtainium периодически проверяет обновления (по умолчанию примерно раз в 6 часов; интервал можно поменять в Settings → «Background update checking»). При появлении новой версии придёт уведомление.
- Проверить вручную: откройте Obtainium → потяните список вниз → у Gym появится кнопка **«Update»**.
- Обновление ставится **поверх** текущей версии: все тренировки и история сохраняются. Удалять приложение не нужно и **не следует** — удаление стирает все данные.

## Для разработки

- Kotlin, Jetpack Compose, Material 3, Room, Navigation Compose. minSdk 26.
- Сборка: `gradlew.bat assembleDebug`, тесты: `gradlew.bat testDebugUnitTest`, lint: `gradlew.bat lint`.
- Release-подпись локально — через git-игнорируемый `keystore.properties` в корне:
  ```
  storeFile=C:/Users/<you>/gym-keystore/gym-release.jks
  storePassword=...
  keyAlias=gym
  keyPassword=...
  ```
- В CI подпись берётся из секретов репозитория `GYM_KEYSTORE_BASE64`, `GYM_KEYSTORE_PASSWORD`, `GYM_KEY_ALIAS`, `GYM_KEY_PASSWORD`.
- Правила для изменений и обзор архитектуры — в [CLAUDE.md](CLAUDE.md).
